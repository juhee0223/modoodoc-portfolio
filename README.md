# Portfolio address redirect

포트폴리오가 [juhee-portfolio](https://juhee0223.github.io/juhee-portfolio/)로 이동했습니다.

이 저장소는 기존 제출 URL의 연결을 유지하기 위한 용도입니다.
기존 홈과 프로젝트 상세 주소에서 새 사이트의 같은 페이지로 자동 이동하며, 쿼리 문자열과 섹션 앵커를 유지합니다.
JavaScript를 사용할 수 없는 경우에는 안내 링크와 기존 내용을 표시합니다.

콘텐츠 수정은 [juhee0223/juhee-portfolio](https://github.com/juhee0223/juhee-portfolio) 저장소에서 진행합니다.
